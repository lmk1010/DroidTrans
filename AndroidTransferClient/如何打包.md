# 🚀 超简单打包指南（M1 Mac 专用）

## 你只需要记住一条命令

```bash
./build_m1.sh
```

就这么简单！🎉

---

## 📝 详细步骤（如果你是第一次）

### 第 1 步：打开终端

在 Mac 上按 `Command + 空格`，输入 "Terminal"，回车

### 第 2 步：进入项目目录

在终端输入：

```bash
cd /Users/liumingkang/Code/AndroidTransfer/AndroidTransferClient
```

### 第 3 步：运行打包命令

```bash
./build_m1.sh
```

**如果提示 "Permission denied"**，先运行：

```bash
chmod +x build_m1.sh
```

然后再运行 `./build_m1.sh`

### 第 4 步：等待完成

脚本会自动：
- ✅ 创建 Python 虚拟环境
- ✅ 安装所有依赖（Flask 等）
- ✅ 打包 Python 后端
- ✅ 安装 Node.js 依赖（Electron 等）
- ✅ 打包成 .dmg 安装包

**预计时间**：
- 首次打包：5-8 分钟（需要下载依赖）
- 后续打包：2-3 分钟

### 第 5 步：找到安装包

打包完成后，在 `dist/` 文件夹找到：

```
Android Transfer-1.0.0-arm64.dmg
```

双击安装即可！

## 🎓 技术细节（可选阅读）

### 打包原理

1. **Python 后端**：使用 PyInstaller 打包成独立可执行文件
2. **Electron 前端**：使用 Electron Builder 打包成 .dmg
3. **最终产物**：包含 Python 运行时 + Flask + Electron 的完整应用

### 打包后的文件结构

```
Android Transfer.app/
├── Contents/
│   ├── MacOS/
│   │   └── Android Transfer    # Electron 主程序
│   └── Resources/
│       └── app/
│           └── app             # Python 后端可执行文件
│               ├── templates/  # HTML 模板
│               └── ...         # 其他资源
```

### 架构说明

- **arm64**：适用于 M1/M2/M3/M4 芯片的 Mac
- **x64**：适用于 Intel 芯片的 Mac

你的打包脚本会自动生成 arm64 版本。
