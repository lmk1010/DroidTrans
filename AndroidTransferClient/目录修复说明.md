# 📁 输出目录修复说明

## 问题原因

打包后的应用无法写入应用内部的 `photos_output` 目录，因为：
1. ❌ macOS 沙盒权限限制
2. ❌ 应用包是只读的
3. ❌ 没有权限在应用目录创建文件

## 解决方案

已修改 `app.py`，使用**智能目录选择**：

### 开发环境（npm start）
```
./photos_output
```
在项目目录中，方便开发测试

### 打包后的应用
```
~/Documents/AndroidTransfer/
```
使用用户的文档目录，有完整的读写权限

## 修改内容

### 1. 添加了智能目录函数
```python
def get_output_dir():
    """获取合适的输出目录"""
    if getattr(sys, 'frozen', False):
        # 打包后：用户文档目录
        home = os.path.expanduser("~")
        output_dir = os.path.join(home, "Documents", "AndroidTransfer")
    else:
        # 开发环境：当前目录
        output_dir = "./photos_output"
    
    os.makedirs(output_dir, exist_ok=True)
    return output_dir

OUTPUT_DIR = get_output_dir()
```

### 2. 数据库路径也改了
```python
def get_db_path():
    """获取数据库文件路径"""
    if getattr(sys, 'frozen', False):
        home = os.path.expanduser("~")
        db_dir = os.path.join(home, "Documents", "AndroidTransfer")
        os.makedirs(db_dir, exist_ok=True)
        return os.path.join(db_dir, 'android_transfer.db')
    else:
        return os.path.join(os.path.dirname(__file__), 'android_transfer.db')

DB_FILE = get_db_path()
```

## 用户体验

打包后，用户的照片会保存在：
```
~/Documents/AndroidTransfer/
├── android_transfer.db          # 数据库
├── device_id_1/                 # 设备1的照片
│   ├── batch_id_1/
│   │   ├── photo1.jpg
│   │   └── photo2.jpg
│   └── batch_id_2/
│       └── photo3.jpg
└── device_id_2/                 # 设备2的照片
    └── ...
```

用户可以轻松在 Finder 中找到：
1. 打开 Finder
2. 前往 → 文稿
3. 找到 `AndroidTransfer` 文件夹

## 其他改进

如果想让用户自己选择目录，可以考虑：
- 在首次启动时弹出目录选择对话框
- 在设置中添加"更改输出目录"选项

但默认使用 Documents 目录是最佳实践，符合 macOS 应用规范。
