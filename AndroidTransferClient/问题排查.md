# 🔧 Electron 应用常见问题排查

## 问题 1: USB 模式无法读取 ADB 设备

### 原因分析

打包后的 Electron 应用找不到 ADB 命令，因为：
1. ❌ ADB 不在系统 PATH 中
2. ❌ 打包的应用没有包含 ADB 工具
3. ❌ macOS 沙盒限制了命令执行

### 解决方案

#### 方法 1: 检查 ADB 是否在 PATH 中（最常见）

```bash
# 检查 ADB 是否可用
which adb

# 如果找不到，安装 Android Platform Tools
brew install android-platform-tools

# 验证安装
adb version
```

#### 方法 2: 修改 Electron 应用启动方式

打包后的应用可能继承不到环境变量，需要显式设置 PATH。

**修改 `electron_main.js`**，在启动 Flask 之前添加 PATH：

```javascript
function startFlask() {
    const isDev = !app.isPackaged;
    
    // 添加 ADB 到 PATH
    const homebrewPath = '/opt/homebrew/bin:/usr/local/bin';
    const platformToolsPath = process.env.HOME + '/Library/Android/sdk/platform-tools';
    process.env.PATH = `${homebrewPath}:${platformToolsPath}:${process.env.PATH}`;
    
    if (isDev) {
        flaskProcess = spawn('python3', ['app.py'], {
            cwd: __dirname,
            env: process.env  // 传递环境变量
        });
    } else {
        const exePath = path.join(process.resourcesPath, 'app', 'app');
        flaskProcess = spawn(exePath, [], {
            env: process.env  // 传递环境变量
        });
    }
    // ... 其余代码
}
```

#### 方法 3: 在应用中包含 ADB（推荐用于分发）

如果要分发给其他用户，最好把 ADB 打包进应用。

## 问题 2: 9500 端口外部无法访问

### 原因分析

1. ❌ macOS 防火墙阻止了入站连接
2. ❌ Flask 绑定到 127.0.0.1（只能本机访问）
3. ❌ 网络配置问题

### 解决方案

#### 方法 1: 配置 macOS 防火墙

1. 打开 **系统偏好设置** → **安全性与隐私** → **防火墙**
2. 点击 **防火墙选项**
3. 点击 **+** 添加你的应用
4. 选择 **允许传入连接**

或者命令行：
```bash
# 关闭防火墙（测试用）
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --setglobalstate off

# 添加应用到白名单
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --add "/Applications/Android Transfer.app"
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --unblockapp "/Applications/Android Transfer.app"
```

#### 方法 2: 检查 Flask 绑定地址

查看 `app.py` 最后一行：
```python
app.run(debug=True, host='0.0.0.0', port=9500, threaded=True)
```

确保是 `host='0.0.0.0'` 而不是 `host='127.0.0.1'`

#### 方法 3: 测试端口是否开放

```bash
# 检查端口是否监听
lsof -i :9500

# 从另一台设备测试（替换为 Mac 的 IP）
curl http://192.168.1.x:9500
```
