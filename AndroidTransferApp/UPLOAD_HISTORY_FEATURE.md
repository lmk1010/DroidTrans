# 上传记录功能说明

## 功能概述

Android客户端现已支持上传记录功能，可以记录每次上传的数量和时间，并支持一键排除已上传的照片。

## 主要功能

### 1. 上传记录保存
- 每次上传完成后，自动保存上传记录到本地SQLite数据库
- 记录内容包括：
  - 服务器名称和地址
  - 上传时间
  - 总数量、成功数量、失败数量
  - 每个文件的详细信息（文件名、路径、大小、是否成功）

### 2. 查看上传历史
- 在主界面（MainActivity）右上角有"上传记录"菜单项
- 点击可进入上传历史记录页面
- 显示所有历史上传记录，包括：
  - 服务器信息
  - 上传时间
  - 统计信息（总数、成功、失败、成功率）
- 支持查看单条记录的详细信息
- 支持删除单条记录
- 支持清空所有记录

### 3. 排除已上传照片
- 在照片选择页面（PhotoSelectionActivity）顶部有"排除已上传"按钮
- 点击后自动过滤掉已经上传过的照片
- 按钮会显示当前已上传照片的数量
- 可以切换显示全部照片或只显示未上传照片

## 数据库设计

### 表结构

#### upload_records 表（上传记录）
- id: 主键
- server_url: 服务器地址
- server_name: 服务器名称
- total_count: 总数量
- success_count: 成功数量
- failed_count: 失败数量
- upload_time: 上传时间戳
- file_list: 文件列表（JSON格式）

#### uploaded_files 表（已上传文件索引）
- id: 主键
- file_path: 文件路径（唯一）
- file_name: 文件名
- file_size: 文件大小
- upload_time: 上传时间戳

## 技术实现

### 核心类

1. **数据模型**
   - `UploadRecord.java` - 上传记录模型

2. **数据库**
   - `DatabaseHelper.java` - SQLite数据库助手
   - `UploadRecordDao.java` - 数据访问对象

3. **界面**
   - `UploadHistoryActivity.java` - 历史记录页面
   - `UploadRecordAdapter.java` - 历史记录列表适配器

4. **功能增强**
   - `UploadProgressActivity.java` - 上传完成后保存记录
   - `PhotoSelectionActivity.java` - 添加过滤已上传照片功能

## 使用流程

1. **正常上传流程**
   ```
   选择照片 -> 上传 -> 上传完成 -> 自动保存记录
   ```

2. **查看历史记录**
   ```
   主界面 -> 点击"上传记录"菜单 -> 查看历史列表
   ```

3. **排除已上传照片**
   ```
   照片选择页面 -> 点击"排除已上传"按钮 -> 自动过滤
   ```

## 特点

- ✅ 自动记录，无需手动操作
- ✅ 本地存储，不依赖网络
- ✅ 智能过滤，避免重复上传
- ✅ 详细统计，了解上传情况
- ✅ 界面友好，操作简单

## 注意事项

1. 上传记录存储在应用本地数据库中，卸载应用会清空记录
2. 文件判断基于文件路径，如果文件被移动或重命名，会被视为新文件
3. 建议定期清理历史记录以节省存储空间
