# 手机互传功能说明

## 功能概述

手机互传功能允许两台Android手机之间直接传输数据，提供两种传输方式：

### 1. USB 点对点传输 ✅ (已实现)

通过USB OTG数据线连接两台手机，实现高速数据传输。

#### 功能特性：

- **OTG功能检测**：自动检测设备是否支持USB OTG功能
- **设备连接检测**：实时检测USB设备连接状态
- **USB版本识别**：自动识别USB版本（USB 2.0, USB 3.0, USB 3.1, USB 3.2等）
- **速率测试**：测试实际传输速率，并与理论速率对比
- **文件传输**：支持照片、视频、文件的实际传输
- **智能存储**：自动检测USB存储设备，支持传输到OTG U盘或Download目录
- **传输进度**：实时显示传输进度、速率、剩余时间
- **兼容性处理**：支持不同USB版本设备之间的连接

#### USB版本与理论速率：

| USB版本 | 理论速率 | 实际速率（约70-80%） |
|---------|----------|---------------------|
| USB 2.0 | 60 MB/s  | 约48 MB/s           |
| USB 3.0 | 500 MB/s | 约350 MB/s          |
| USB 3.1 Gen 2 | 1000 MB/s | 约700 MB/s    |
| USB 3.2 Gen 2x2 | 2000 MB/s | 约1400 MB/s |

#### 使用步骤：

1. 点击主页的"手机互传"卡片
2. 选择"USB 点对点传输"
3. 系统会自动检测OTG功能并请求存储权限
4. 使用OTG数据线连接两台手机或插入OTG U盘
5. 点击"开始测速"测试传输速率
6. 选择要传输的照片、视频或文件
7. 点击"开始传输"开始数据传输
8. 文件将自动保存到USB存储设备或Download/AndroidTransfer目录

#### 所需硬件：

- 支持OTG功能的Android手机
- USB OTG数据线或OTG U盘
- （推荐）OTG U盘用于存储传输的文件

### 2. 无线点对点传输 🚧 (即将推出)

通过Wi-Fi Direct技术连接两台手机，无需数据线即可传输。

#### 计划功能：

- Wi-Fi Direct自动配对
- 二维码扫描连接
- 无线传输进度显示
- 断点续传支持

## 技术实现

### 核心类：

1. **PhoneTransferActivity.java**
   - 手机互传选择页面
   - 提供USB和无线两种传输模式的入口

2. **UsbP2PActivity.java**
   - USB点对点传输主页面
   - 实现OTG检测、设备连接检测、速率测试

3. **UsbTransferActivity.java**
   - USB数据传输页面
   - 处理实际的文件传输（已完成）
   - 支持传输到USB存储设备或Download目录
   - 实时显示传输进度和统计信息

### 权限要求：

```xml
<!-- USB Host模式权限 -->
<uses-feature android:name="android.hardware.usb.host" android:required="false" />

<!-- 存储权限 -->
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
<uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />
```

## 注意事项

1. **OTG支持**：并非所有Android设备都支持OTG功能，使用前请确认
2. **数据线质量**：建议使用原装或品质较好的OTG数据线
3. **电源供应**：某些设备可能需要外接电源支持OTG功能
4. **USB版本**：实际传输速率取决于两台设备中较低的USB版本
